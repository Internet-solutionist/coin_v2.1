**Sovereign 6-Agent AI Trading Firm**

## Quick Start

```bash
git clone https://github.com/Internet-solutionist/coin_v2.1.git
cd coin_v2.1
cp .env.example .env
docker compose up --build
```

Open http://localhost:8000/docs to test the full 6-agent cycle.
