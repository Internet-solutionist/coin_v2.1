# coin_v2.1 — CoIn Counter Insurance

**Sovereign 6-Agent AI Trading Firm**

We do not predict the market. We insure against it.

Built as a complete, local-first, diagnostic trading firm using your own capable models.

## Quick Start

```bash
git clone https://github.com/Internet-solutionist/coin_v2.1.git
cd coin_v2.1
cp .env.example .env
 docker compose up --build
```

Open http://localhost:8000/docs and run `/cycle` to start the 6-agent diagnostic process.
